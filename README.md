# The Fly and the Spider

A small in-browser simulation: a garden spider (*Araneus diadematus*) on its orb web in a window corner, with house flies and greenbottles crawling on the glass. The flies walk, groom and take off. Now and then one flies into the web and gets stuck, struggles and is wrapped by the spider. The web is a mass-spring model, so it sways in the wind, sags under the spider and trembles when a fly struggles.

**Live:** https://dinoel.github.io/fly-spider/

Plain HTML, SVG and canvas, with no build step or dependencies. To run it locally, open `index.html`.

**Controls:** space pauses; `1` / `3` / `0` set the speed; `+` adds a fly; `H` hides the panel. Click the web and the spider comes to check it. Click near a fly to scare it off.
